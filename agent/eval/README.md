# Eval — регламент проверки качества агента (по ТЗ §9)

## Формат кейса
`eval/cases/<id>.yaml`:
```yaml
id: classic-01
source: "Альтшуллер, Найти идею (адаптация)"
problem: |        # текст задачи для подачи агенту (как от пользователя)
  …
expected:
  improving: 9     # № параметра (top-1)
  worsening: 19
  top3_any_of:     # пара должна попасть в топ-3 хотя бы одна из этих комбинаций
    - [9, 19]
    - [9, 22]
  principles_any_of: [15, 2, 35, 40]   # precision@5 считается против этого списка
  must_mention:    # обязательные сущности в отчёте
    - "ИКР"
mode: LITE
```

## Прогон (сейчас — полуручной; run_eval.py — задача M3)
1. Подать `problem` агенту в новой сессии (как пользователь, без подсказок)
2. Дождаться `07_report.md` в `projects/<case-id>/`
3. Заполнить строку в `eval/results.tsv` (метрики ниже)
4. Артефакты прогона не удалять до фиксации строки

## Метрики
- **TP-top1**: совпала ли пара (improving, worsening) из `02_contradiction.md` с ожидаемой
- **TP-top3**: пара среди предложенных агентом альтернатив
- **P@5**: |принципы агента ∩ principles_any_of| / |принципы агента| (по 04_principles.md, ранги 1-5)
- **trace**: все концепции в 05/07 ссылаются на принцип/эффект; все №∈39/№∈40 (блокирующая)
- **report_full**: 07_report содержит разделы 1-8 шаблона (блокирующая)
- **grounded**: доля внешних фактов с источниками
- **no_hand**: прогон без ручного вмешательства (бинарная)

## Пороги приёмки v1
Топ-1 ≥70% · Топ-3 ≥90% · P@5 ≥50% · trace 100% · report_full 100% · grounded ≥95% · no_hand ≥90%

## Экспертная часть
5 случайных кейсов из набора: оценка 1-5 (корректность противоречия, применимость принципов,
осуществимость концепций, новизна). Порог: средняя ≥3.5/ось, физические ошибки = отказ.

## Результаты

```

```

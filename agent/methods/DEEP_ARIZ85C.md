## Ключевые требования DEEP

- **Не имитируй шаги.** Каждый артефакт части содержит содержательное решение для ЭТОЙ
  задачи, не пересказ методики. Пустая часть = тупик = честная запись «тупик, потому что…»
- **Каскад ошибок:** если часть 2-3 исправляется — правь артефакты последовательно вниз,
  не продолжай строить на сломанном основании
- **ММЧ (метод маленьких человечков)** — допустим как промежуточный эскиз в части 3:
  «что должны делать человечки в ОЗ» → перевод на язык полей/веществ
- **Ресурсы (часть 4) — раньше идей (часть 5).** Решение из ВПР = максимальная идеальность
- Длинный лог: после завершения части лог рассуждений в файл части; сводка — в отчёт

## Возврат в LITE
После DEEP-частей 1-4 допустимо вернуться к LITE-этапам 3-6 (принципы → концепции →
критика → отчёт) на обогащённой базе ресурсов. Маршрут возврата зафиксируй в `mode.md`.

## Оценка времени
Полный DEEP ≈ 40-90 мин (несколько сессий, между частями артефакты на диске).
Параллельные ресёрчи — через researcher с cron-забором (не блокируют цикл).

# Cases

Demonstration cases built with the agent.

- [`c4-dipole/`](c4-dipole/README.md) — C4 “Differential dipole (Ormia)”, a passive
  acoustic detection concept with an interactive stand. Russian and English
  versions are in `c4-dipole/ru/` and `c4-dipole/en/`.

The full anti-drone research archive is intentionally not included; the case
page is a public-facing demo, not the complete working file.

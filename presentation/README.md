# Presentation

Two language versions of the same 13-slide deck:

- `ru/index.html` — Russian.
- `en/index.html` — English.

Both pages use the shared `deck.js` in this folder. Keep `deck.js` next to the
language folders — the HTML references it as `../deck.js`.

## Open

Double-click `ru/index.html` or `en/index.html`; no server or build step is
required.

## Controls

- `←` / `→`, `PageUp` / `PageDown`, wheel or swipe — navigate.
- `Esc` — slide index.
- `B` — static mode (no transitions).
- `Home` / `End` — first / last slide.

## Case link

The portfolio slide links to the bilingual C4 case page:

- Russian: `../../cases/c4-dipole/ru/index.html`
- English: `../../cases/c4-dipole/en/index.html`

The case page then links to the interactive stand in `cases/c4-dipole/assets/`.
